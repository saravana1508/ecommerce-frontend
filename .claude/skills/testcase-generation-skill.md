---
name: Test Case Generation Skill
description: Generates functional and validation test cases for enterprise applications
---

# Instructions

When generating test cases:
1. Understand the feature or bug clearly
2. Include positive and negative scenarios
3. Cover validation and authorization checks
4. Include expected results

# Output Format

- Test Case ID
- Scenario
- Steps
- Expected Result
- Status

# Validation Rules

- Verify role-based access
- Validate UI visibility
- Check API response behavior
- Ensure proper error handling
